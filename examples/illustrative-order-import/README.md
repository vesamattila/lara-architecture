# Illustrative order-import reconstruction

> **ILLUSTRATIVE ONLY:** This is a synthetic, redistributable example written for LARA. It was not generated by an actual LARA run, does not describe a real employer or customer system, and does not claim that the methodology has been executed successfully.

The tiny source fixture imports JSON orders into a processed directory. The example follows one claim through the LARA reasoning chain:

```text
synthetic source + test
        ↓
OBSERVED evidence
        ↓
INFERRED decision + UNKNOWN rationale/scope
        ↓
recovered ADR
        ↓
independent skeptical review
        ↓
NARROWED decision
```
